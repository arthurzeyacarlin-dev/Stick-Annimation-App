The AI Animator Engine is the interactive AI assistant integrated into the animation workspaces.

The engine appears in the bottom-right panel of the workspace interface.

This panel allows the user to communicate with the AI and request animation assistance.

The AI panel contains three primary controls.

The message input field
The reasoning level control
The task selector

The reasoning level control allows the user to choose how deeply the AI should analyze the request.

Higher reasoning levels allow the AI to perform more complex animation tasks.

The task selector allows the user to choose the type of task the AI should perform.

Examples include generating frames, generating sound effects, or assisting with animation improvements.

Only one task may run at a time.

When the AI performs an action, the system displays progress feedback such as generation indicators or progress bars.

The AI may also trigger global notifications when tasks complete.

These notifications appear with a blue gradient header and can be dismissed by the user.
