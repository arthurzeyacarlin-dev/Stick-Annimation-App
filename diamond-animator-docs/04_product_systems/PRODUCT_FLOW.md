The Product Flow describes how users move through the Diamond Animator application.

The application begins on the main screen.

From the main screen the user can perform several primary actions:

Create a new project
Open an existing project
Learn how to use the application
Access AI assistance
Use export and tool features

When creating a project, the user chooses the animation workspace.

Once inside the workspace the user can animate using drawing tools, stick figure tools, or AI assistance.

When the animation is complete, the user may export the project using the Export System.

This flow ensures that users can move smoothly from learning the software to producing animation content.
