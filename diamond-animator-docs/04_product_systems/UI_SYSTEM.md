The main screen contains a header area displaying the application name and navigation options.

Below the header the interface presents the primary application sections.

These include project creation, project opening, tutorials, AI assistance, and tool features.

Buttons include icons and descriptive text explaining their function.

The interface uses a dark color theme with subtle blue accents to reflect the Diamond Animator visual identity.

Workspaces use a consistent layout consisting of a top toolbar, a central canvas or stage, a right-side control panel, and a bottom timeline.

The UI System ensures visual consistency across all parts of the application.
