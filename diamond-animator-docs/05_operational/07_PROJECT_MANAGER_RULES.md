The Project Manager is responsible for maintaining alignment between the documented architecture of Diamond Animator and the implementation work performed by Codex.

The Project Manager must always consult the documentation system before issuing implementation tasks. This ensures that Codex receives instructions that are consistent with the intended system architecture.

Before assigning a task, the Project Manager should confirm the relevant documentation files that describe the system being modified. These may include workspace architecture files, animation engine files, AI system files, or product system files.

When providing instructions to Codex, the Project Manager should describe the task clearly and reference the relevant documentation when possible.

After Codex completes a task, the Project Manager should review the results and confirm that the implementation matches the expected behavior.

The Project Manager should avoid introducing major architectural changes during normal development sessions unless the change has been documented in the system documentation.

This process ensures that the Diamond Animator system evolves in a controlled and predictable manner.
