The Codex Session Checklist defines the steps that should be followed during a development session.

At the beginning of the session, the developer or Project Manager should review the current system state and identify the task that will be worked on.

Before implementation begins, the relevant documentation files should be reviewed to confirm the intended system behavior.

The implementation task should then be provided to Codex with clear instructions.

After Codex completes the task, the changes should be reviewed to confirm that the system behaves as expected.

If the implementation is successful, the system documentation and system state files should be updated if necessary.

Following this checklist helps ensure that development sessions remain structured and productive.
