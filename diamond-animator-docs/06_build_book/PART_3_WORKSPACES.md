Part 3 — Animation Workspaces

Diamond Animator provides two primary animation workspaces.

The Drawing Workspace supports traditional drawing-based animation.

This workspace allows users to create animation by drawing frames directly on the canvas.

Tools within this workspace allow users to sketch, refine, and animate drawings using a timeline-based workflow.

The Stick Figure Workspace supports simplified character animation using stick figure rigs.

This workspace focuses on pose manipulation and motion control rather than frame-by-frame drawing.

Both workspaces share a consistent layout structure.

A toolbar appears at the top of the interface.
A canvas or stage appears in the center.
Control panels appear on the right side.
The animation timeline appears at the bottom.

Both workspaces also integrate AI assistance tools that help users accelerate their animation workflow.
